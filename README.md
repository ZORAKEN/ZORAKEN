### 🧠 Book Review Sentiment Analysis

**NLP · TF-IDF · Scikit-learn**

Natural Language Processing project for classifying book reviews using text preprocessing, TF-IDF feature extraction, machine learning models, and hyperparameter tuning.

---

### 👕 Fashion-MNIST Classification

**PyTorch · Deep Learning · GPU**

Image classification project exploring neural networks, GPU acceleration, Batch Normalization, Dropout, and hyperparameter optimization.

---

**Generative AI · Audio Processing · Flow Matching**
